# CGPA Calculator 🎓

A simple and responsive CGPA (Cumulative Grade Point Average) calculator built using modern web technologies. Designed to help students accurately compute their CGPA based on course units and grades.

🌐 [Live Demo](https://mygp.netlify.app/)

---

## 🚀 Features

- Easy-to-use interface
- Add unlimited courses
- Auto-calculation of CGPA
- Real-time updates as you input data
- Responsive design (mobile & desktop friendly)
- Clean and minimal UI

## 📚 How to Use

1. Enter your **course title**, **credit unit**, and **grade**.
2. Click **Add Course** to include it in the list.
3. The calculator will automatically compute your CGPA based on the inputs.
4. Clear or modify the list as needed.

---

## 🧠 How CGPA is Calculated

The calculator uses this formula:

Total Grade Points = ∑ (Credit Unit × Grade Point)
CGPA = Total Grade Points ÷ Total Credit Units
